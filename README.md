One pickup line, 200 characters at most, spoken by a vending machine to a
passing human — entry for the [One Line, One Minute: The Vending Machine
Pickup Line Contest](https://make.fun/competitions/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee)
on make.fun.

## The line

> Insert coin, press my heart, and watch me drop everything for you.

## How it runs

`main.ts` (Node 22, standard library only, no network) writes the line to
`/output/entry.txt`:

```sh
node main.ts
```

The line was picked by an internal pairwise tournament over 12 original
candidates — see `tournament.md` for the full bracket.
